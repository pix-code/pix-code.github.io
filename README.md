# [dukebr.org](https://dukebr.org)
Welcome to the source code for my personal website! It is written with static html/css, and heavily inspired by the design minimalism of [myrdin.cx](https://myrdin.cx/). This was mainly a project to teach myself the basics of HTML and CSS, so please excuse any code that does not follow best practices.

## Example usage:
```
python -m http.server 8080
```

then visit http://localhost:8080
